# Источники ресурсов

Оформление основано на двух пользовательских скриншотах MAX: тёмная мобильная переписка и светлая веб-версия. В обновлённой версии аватары демонстрационных контактов показываются из этих референсов через SVG viewBox: изображения `reference-mobile.png` и `reference-desktop.png` служат источниками. Скриншот с ключами GREEN-API в ресурсы приложения не включён.

Оригинальные ресурсы найдены в публичной веб-версии [MAX](https://web.max.ru/) и сохранены локально для стабильной загрузки:

Логотип и узор принадлежат их правообладателям. Использованы в тестовом задании для воспроизведения заданного интерфейса; отдельная лицензия на распространение этих брендовых ресурсов не заявляется.

Иконки — lucide-react (ISC). Фронтальная рамка iPhone реализована как геометрическая оболочка интерфейса, а не фотография устройства. Соотношение сторон экрана 402:874 следует разрешению 1206:2622 из [технических характеристик iPhone 17](https://www.apple.com/iphone-17/specs/). Системные элементы стилизованы; это веб-приложение, а не эмулятор iOS.
