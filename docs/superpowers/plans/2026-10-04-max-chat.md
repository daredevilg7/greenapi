# MAX Chat Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan in this session. Steps use checkbox syntax for tracking.

**Goal:** Локально готовое React-приложение для текстовых сообщений MAX, с выбором телефона/компьютера и точностью к пользовательским референсам.

**Architecture:** Транспорт HTTP GREEN-API и последовательный poller не зависят от React. ChatStore хранит общую переписку; React использует useSyncExternalStore и две визуальные оболочки. Ключи живут только в памяти.

**Tech Stack:** React, TypeScript, Vite, lucide-react, Vitest, Testing Library.

**Spec:** docs/superpowers/specs/2026-10-04-max-chat-design.md

## Global Constraints
- Только текст; максимум 4000 символов; телефоны РФ/РБ.
- Два визуальных режима, одна сессия. Локальная работа без публикации.
- Токен не сохраняется в storage, исходниках и логах.
- Квитанция подтверждается после обработки, повтор не дублирует сообщение.
- Демонстрационные данные и реальные диалоги разделены.

## Review Focus
- Потеря сети в момент отправки не должна создавать автоматический повтор.
- Смена сессии во время запроса не должна добавлять чужие сообщения.
- Ошибка удаления квитанции не должна повторно применять сообщение.
- Исходящее API-уведомление не должно дублировать оптимистичное сообщение.
- Мобильная клавиатура и ограниченная высота экрана не должны перекрывать ввод.
